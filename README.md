# Jejak Teman Jalur

Website statis untuk Jejak Teman Jalur.

## Folder & File
- `index.html`
- `style.css`
- `script.js`
- `logo-jejakteman.png`

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `jejak-teman-jalur`.
2. Jalankan di folder ini:
   ```bash
   git remote add origin https://github.com/<username>/jejak-teman-jalur.git
   git branch -M main
   git push -u origin main
   ```
3. Buka GitHub repo → Settings → Pages.
4. Pilih branch `main` dan folder `/(root)`.
5. Simpan. Link akan menjadi: `https://<username>.github.io/jejak-teman-jalur/`
